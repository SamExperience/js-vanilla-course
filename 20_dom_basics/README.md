# 20 — DOM basics (LESSON 44)

The first browser topic: your code stops printing to the console and starts changing
the page.

## Path

**1. Read the lesson** — `dom_basics.ipynb`, same as every topic so far.

**2. Run the project, then read the demo** — `npm install` (first time), then
`npm run dev` inside `project/`. Open the address Vite prints and press **F12** for the
console. Now open `src/lessons/lesson-44-dom-basics.js` beside the page: it builds
everything in the *Lesson demo* box. Match each line to what you see.

**3. Do the exercise** — `src/exercise/exercise.js` holds **4 numbered STEPs**, each
with a `// Check:` line. One STEP at a time; the page reloads when you save.

**Done when:** clicking counts 1, 2, 3… and the number is red from 10 onwards.

## If you get stuck

Paste `ai-prompt.txt` into a new session with an AI assistant: it guides you with
questions instead of handing you the answer. `src/exercise/solution.js` is a last
resort, not a first move.
